# Plans

Working plan documents (migration plans, design notes, roadmaps drafted before
implementation) live in this folder.

Convention:

- Save every plan here as a Markdown file, e.g. `docs/plans/<slug>.md`.
- Plan files are **gitignored** — they are local, in-progress scratch, not
  committed artifacts. Only this `README.md` is tracked.
- Once a plan's decisions are finalized, promote the durable parts into the
  appropriate committed doc (SPEC, README, ADR, etc.); the plan itself stays local.
